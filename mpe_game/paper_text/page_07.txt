C. Off-Policy RL Algorithm Design
In this section, an off-policy RL algorithm based on the
foundation of Algorithm 2 is proposed. Note that Algorithm 2
requires the knowledge of value functions Vi(x) to solve the
approximate HJI equation. Thus, we leverage the approximating
characteristics of neural networks to address this issue. In the
case of multiple agents, the application of multiple networks
introduces computational burden. Therefore, we adopt the V -
SNAC structure. In this structure, for each evader, only one critic
network is utilized to captures the mapping between states and
the value functions Vi(x). In MPE game, all the agents will
continuously and simultaneously update the network weights.
