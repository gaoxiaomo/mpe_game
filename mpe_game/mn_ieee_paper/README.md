# mn_ieee_paper

IEEE conference-style manuscript for the generalized nonlinear pursuit-evasion framework.

## Files
- `paper.tex`: main manuscript
- `refs.bib`: bibliography database
- `figs/`: figures copied from the generalized experiments

## Compile
Recommended:
- `latexmk -pdf paper.tex`

Or:
- `pdflatex paper.tex`
- `bibtex paper`
- `pdflatex paper.tex`
- `pdflatex paper.tex`
