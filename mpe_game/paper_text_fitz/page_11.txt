V. CONCLUSION
An approximate optimal control strategy based on reinforce-
ment learning has been designed and applied to the multiagent
PE game in this article. The relationships between agents are
represented using graph models. The MPE game is constrained
by actuator saturation and nonlinear system dynamics. Initially,
using the proposed approximate HJI equation, we present an
on-policy PI algorithm with convergence analysis. Then, to
approximate the value functions, an off-policy RL method is in-
troduced. This algorithm efﬁciently solves the approximate HJI
equationandprovidessolutionsundermultiagentconditions.We
utilize a network based on the V-SNAC structure to implement
this off-policy RL method. Furthermore, it is noteworthy that
the proof of the network system’s UUB is provided. Finally, we
conduct simulations in two distinct scenarios: multiple-pursuer-
one-evader and multiple-pursuer-multiple-evader. Comparative
analyzes on cohesion and computational burden are employed
to verify the effectiveness. In future research, attention can be
focused on enhancing the collaboration among evaders, as well
as addressing the problem of MPE in situations with limited
state perception and communication.
