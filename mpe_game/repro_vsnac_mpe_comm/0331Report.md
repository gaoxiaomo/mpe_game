# 组会汇报

## 本周工作进展

上周老师建议从计算性能方面入手，跟原文做对比分析。实际推进过程中碰到了两个问题：一是原文（Xu2024）的代码没有公开，我们的复现在一些实现细节上不可能完全一致，比如初始状态的生成方式、逃逸者的运动策略等，这些差异会直接影响计算量的数值；二是我们的框架多了一层通信协调，如果单纯拿运行时间来比，结论就是"多了一层所以慢了"，这个对比本身说明不了什么问题，也不太好作为有价值的实验结果来呈现。

因此我调整了思路，回过头去仔细分析原文方法的局限性，看能不能找到一个值得改进的点。分析之后发现了一个比较明确的问题：原文的多追逐者系统中，每个追逐者通过V-SNAC独立求解自己的最优控制策略，优化目标是让追踪误差收敛到编队偏移量r对应的位置。这个设计在单个追逐者的层面是最优的，但它**完全没有考虑追逐过程中追逐者之间的相对距离**。当两个或多个追逐者被分配到同一个逃逸者时，如果它们的初始位置和编队偏移导致最优轨迹在空间上交叉，就会出现追逐者之间距离过近甚至碰撞的情况。这在实际的无人机或飞行器编队追踪任务中是一个比较严重的安全隐患。

基于这个发现，我把"追逐过程中的空间协调"作为创新点，在原有V-SNAC框架上增加了一层通信协调机制。具体做法是：在指派到同一逃逸者的追逐者之间建立通信图，设计一个速度-位置耦合的PD型协调势函数，然后把它和学习到的追踪值函数叠加构成增广值函数。追逐者的控制律从增广值函数的梯度在tanh饱和函数内推导得出。这样做的好处是追踪和协调共享同一个tanh的有限控制力，分配是自然的，不需要人为设定优先级。理论上也说得通，因为协调势只涉及追逐者状态，不影响逃逸者的最坏情况策略，V-SNAC的权重更新也不受影响。

仿真部分目前已经全部跑完：

1. **受控交叉场景**：专门构造了两个追逐者路径必须交叉的情况。无协调时两个追逐者直接碰撞（最小间距接近0），加入协调后间距始终保持在1km以上，Table I给出了不同协调强度γ下的间距数据，γ从0.5到10单调递增并饱和。
2. **6追3六自由度场景**：在非线性飞行器模型上验证了完整框架。追踪误差符合UUB收敛，动态目标分配能纠正次优的初始指派，15%通信丢包下收敛曲线几乎没有变化。
3. **3追3对照组**：每个逃逸者只有一个追逐者，协调机制正确禁用，验证了增广控制律在不需要协调时退化为基线控制。
4. 论文初稿中英文版均已完成，IEEE 6页格式，包含理论推导、受控场景验证和6-DOF仿真实验，已投出
