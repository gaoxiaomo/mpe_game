\begin{abstract}
针对非线性动力学与执行器饱和约束下的多追逐者多逃逸者追逃博弈问题，
本文提出一种基于增广值函数的分层协同控制框架。
该框架集成三个层面：
（一）采用V-SNAC结构从值函数梯度直接推导饱和Nash均衡控制策略，
相比传统actor-critic架构减少约31\%的网络数量；
（二）基于图论的逐对交换算法实现动态目标重分配，改善团队内聚性；
（三）在同组追逐者间通过通信图引入解析协调势函数，
与学习得到的追踪值函数构成增广值函数，
追逐者控制由增广梯度在$\tanh$饱和内推导得出，
鼓励空间多样性的同时保持执行器约束。
理论上证明了增广值函数满足增广HJI方程，
并建立了与基于势函数的奖励塑形之间的联系。
在六自由度非线性飞行器模型上的五种团队配置（3追1至8追4）实验表明，
该框架在保持捕获性能的同时实现了有效的空间协调，
且在30\%通信丢包率下仍保持鲁棒性。
\end{abstract}

\section{引言}
% =====================================================================

多智能体追逃博弈是对抗决策与协同控制的交叉研究领域，
在无人机编队拦截\cite{b_zhang2023}、卫星对抗\cite{b_gong2020}、
边界防御\cite{b_shishika2020}以及城市空域安全\cite{b_collision_uav}等场景中具有重要应用。
当追逐者数量大于逃逸者时，如何利用数量优势实现高效协同捕获
是该领域的核心问题\cite{b_isaacs,b_chen2016,b_yan2022}。

求解两方追逃博弈的经典方法基于Hamilton--Jacobi--Isaacs (HJI)方程\cite{b_isaacs}，
其解给出鞍点均衡策略。
然而，将HJI分析推广到多智能体非线性系统面临维数灾难。
强化学习(RL)为近似求解HJI方程提供了数据驱动的途径\cite{b_lewis1998,b_lopez2020}。
在多智能体RL领域，MADDPG\cite{b_maddpg}框架引入了集中训练分散执行的范式，
通信感知架构\cite{b_commrl2025}则通过显式消息传递提升协作能力。
在微分博弈方面，图博弈理论将博弈交互建模在通信拓扑上
\cite{b_lopez2020,b_graphgame2023}，
共识控制利用图拉普拉斯实现编队协调\cite{b_ren2005,b_olfati2004}，
控制壁障函数提供安全性保证\cite{b_ames2017}，
加权拓扑协同追踪已应用于追逃博弈\cite{b_zhou2024}，
RL编队围捕控制在四旋翼追逃场景中也有探索\cite{b_formrl2024}。
有限观测下的Nash策略同样受到关注\cite{b_graphswap}。

尽管已有大量研究，在非线性系统与执行器饱和约束下，
同时实现高效个体最优控制、灵活目标分配和有效编队协调仍是一个开放挑战。
现有工作往往聚焦其中一到两个方面，
尚未在统一框架内——尤其是具有严格值函数解释的框架内——兼顾三者。

本文围绕\emph{增广值函数}概念，提出面向非线性追逃博弈的分层协同控制框架，
主要包含三个层面：
\begin{itemize}
\item \textbf{个体控制层}：
  采用V-SNAC结构从值函数梯度直接推导$\tanh$饱和控制策略，
  每个追逐者仅需一个critic网络，
  网络总数从$2(N_p + N_e)$降至$N_p$。
  逃逸者最坏情况控制由同一值函数解析推导。
  权重通过带衰减学习率的离策略梯度下降更新，确保收敛稳定。
\item \textbf{目标分配层}：
  基于图论的逐对交换算法根据实时状态动态调整追逐者-逃逸者指派，
  保证团队内聚性单调改善。
\item \textbf{通信协调层}：
  在同组追逐者间建立通信图，
  引入解析协调势函数$\Phi_j$与学习值函数组合为增广值函数$V_j^{\mathrm{aug}}$。
  追逐者控制由$V_j^{\mathrm{aug}}$的梯度在$\tanh$饱和内推导，
  鼓励空间多样性的同时保持执行器约束。
  协调信号在通信丢失时自然退化，
  并建立了与基于势函数的奖励塑形\cite{b_ng1999}之间的理论联系。
\end{itemize}

本文后续安排如下：
第二节介绍系统模型、代价泛函、V-SNAC控制框架（含逃逸者最坏情况策略）和动态目标分配；
第三节提出通信增广控制理论，包含增广值函数、追逐者与逃逸者的控制律及理论性质；
第四节给出多场景实验与分析；
第五节总结全文。

\section{预备知识}
% =====================================================================

\subsection{智能体动力学}

考虑$N_p$个追逐者和$N_e$个逃逸者（$N_p \geq N_e$）的追逃博弈。
每个智能体服从控制仿射非线性动力学：
\begin{equation}\label{eq:dynamics}
\dot{x}_j = f(x_j) + g(x_j)\,u_j, \quad \|u_j\| \leq \bar{u}
\end{equation}
其中$x_j = [p_j^T, v_j^T]^T \in \mathbb{R}^n$为位置-速度状态，
$u_j \in \mathbb{R}^m$为受饱和约束的控制输入。
本文采用六自由度飞行器模型，漂移项$f(x)$包含气动力
（推力、阻力、升力、俯仰力矩），
输入矩阵$g(x)$满足：
\begin{equation}\label{eq:g_struct}
g(x) = \begin{bmatrix} 0_{3\times 3} \\ G_v(x) \end{bmatrix},
\quad G_v \approx I_3
\end{equation}
即控制输入作用于速度通道的加速度。

\subsection{代价泛函与HJI方程}

追逐者$j$指派到逃逸者$\sigma(j)$，追踪误差定义为：
\begin{equation}\label{eq:error}
\tilde{x}_j = x_j^p - x_{\sigma(j)}^e + r_{j,\sigma(j)}
\end{equation}
其中$r_{j,\sigma(j)}$为围捕编队的期望偏移量。零和代价泛函为：
\begin{equation}\label{eq:cost}
J_j = \int_0^\infty \!\Big[\tilde{x}_j^T Q\,\tilde{x}_j + U(u_j^p) - W(u_e)\Big]\,dt
\end{equation}
其中$U$和$W$为通过Legendre变换处理有界控制的非二次代价项：
\begin{equation}\label{eq:nq}
U(u) = \sum_{l=1}^m 2\bar{u}\,R_{1,l}\int_0^{u_l/\bar{u}} \bar{u}\,\mathrm{arctanh}(\tau)\,d\tau
\end{equation}
$W(u_e)$以惩罚矩阵$R_2$和约束$\bar{u}_e$类似定义。

鞍点值函数$V_j^*(\tilde{x}_j)$满足HJI方程：
\begin{equation}\label{eq:hji}
0 = \tilde{x}_j^T Q\,\tilde{x}_j + (\nabla V_j^*)^T f_j + \min_{u_j^p}\max_{u_e} \Big[U(u_j^p) - W(u_e) + (\nabla V_j^*)^T g_j u_j^p - (\nabla V_j^*)^T g_e u_e\Big]
\end{equation}

\subsection{V-SNAC最优控制}

对Hamiltonian分别关于追逐者和逃逸者控制求驻点，可得Nash均衡策略的解析形式。

\textit{追逐者最优控制}。令$\partial H/\partial u_j^p = 0$，利用非二次代价$U$的结构可得：
\begin{equation}\label{eq:ctrl_pursuer}
u_j^{p*} = -\bar{u}_p\,\tanh\!\bigg(\frac{1}{2\bar{u}_p}\,R_1^{-1}\,g_j^T\,\nabla V_j^*\bigg)
\end{equation}
$\tanh$函数自然保证$\|u_j^{p*}\| \leq \bar{u}_p$。

\textit{逃逸者最坏情况控制}。类似地，令$\partial H/\partial u_e = 0$可得：
\begin{equation}\label{eq:ctrl_evader}
u_e^{*} = -\bar{u}_e\,\tanh\!\bigg(\frac{1}{2\bar{u}_e}\,R_2^{-1}\,g_e^T\,\nabla V_j^*\bigg)
\end{equation}
逃逸者最大化代价，但$\tanh$形式源于相同的变分结构。
由于逃逸者控制以负号进入$J_j$，所得策略驱使逃逸者远离追逐者。

在V-SNAC框架中，值函数被近似为参数线性形式：
\begin{equation}\label{eq:vsnac}
\hat{V}_j(\tilde{x}_j) = \hat{W}_j^T\,\psi(\tilde{x}_j)
\end{equation}
采用6维多项式基函数：
\begin{equation}\label{eq:basis}
\psi(\tilde{x}) = g_\psi\!\cdot\!\big[p_1 v_1,\; p_2 v_2,\; p_3 v_3,\; \tfrac{1}{2}v_1^2,\; \tfrac{1}{2}v_2^2,\; \tfrac{1}{2}v_3^2\big]^T
\end{equation}
其中$g_\psi$为缩放常数，$(p_i, v_i)$为$\tilde{x}$的位置和速度分量。
该基函数捕捉了驱动最优拦截的位置误差-速度耦合的本质特征。
相比传统actor-critic结构（需要$2(N_p + N_e)$个网络），
V-SNAC仅需$N_p$个critic网络——对典型配置减少约31\%。

权重通过带衰减学习率的离策略最小二乘梯度下降更新：
\begin{equation}\label{eq:weight_update}
\hat{W}_{j,s+1} = \hat{W}_{j,s} - \alpha_s\,e_{j,s}\,K_{j,s}^T, \quad \alpha_s = \alpha_0\,\lambda^s
\end{equation}
其中$e_{j,s}$为时间差分误差，$K_{j,s}$为回归方向，
指数衰减学习率$\alpha_s$（$\lambda \in (0,1)$）使收敛曲线呈现
"快速下降$\to$稳定平台"的自然形态。
权重收敛到真实值函数参数的一致最终有界(UUB)邻域\cite{b_lewis1998}。

\subsection{动态目标分配}

在多逃逸者场景中，追逐者-逃逸者指派通过逐对交换算法动态调整\cite{b_graphswap}。
对任意追逐者对$(j, j')$分别指派到逃逸者$(i, i')$，
算法评估交换指派是否使加权距离之和降低超过阈值$\varrho > 0$：
\begin{equation}\label{eq:swap}
d(j,i) + d(j',i') - d(j,i') - d(j',i) > \varrho
\end{equation}
若满足则执行交换。该贪心机制保证团队状态误差$E_{\mathrm{team}}$单调下降，
并收敛到局部最优分配。阈值$\varrho$防止均衡附近的振荡行为。

\section{通信增广控制}
% =====================================================================

个体控制和目标分配层分别解决了追踪最优性和分配效率问题，
但尚未考虑同组追逐者之间的空间关系。
当多个追逐者独立优化相似的追踪目标时，
它们可能收敛到几乎相同的接近轨迹——
既降低了包围效率，也增加了实际部署中飞行器间近距冲突的风险
\cite{b_icao_separation,b_collision_uav}。
通信协调层通过对值函数的原理性增广来解决这一问题。

\subsection{组内通信图}

在追踪同一逃逸者的追逐者之间建立通信图$\mathcal{G}_p = (\mathcal{V}_p, \mathcal{E}_p)$：
\begin{equation}\label{eq:adj}
a_{jk} = \begin{cases} 1, & \sigma(j) = \sigma(k),\; j \neq k \\ 0, & \text{其他} \end{cases}
\end{equation}
度$d_j = \sum_k a_{jk}$。
图拓扑随目标分配演化：当逐对交换算法重新指派追逐者时，
邻接矩阵相应更新。
组内限制确保协调仅作用于接近轨迹确实存在重叠风险的智能体之间，
遵循共识控制中倡导的局部性原则\cite{b_ren2005,b_olfati2004}。

\subsection{协调势函数}

对每个$d_j > 0$的追逐者$j$，定义逐对排斥核$\varphi: \mathbb{R}_+ \to \mathbb{R}_+$
和协调势函数：
\begin{equation}\label{eq:phi}
\Phi_j(p_j, \{p_k\}) = \frac{\gamma}{d_j}\sum_{k:\,a_{jk}>0} \varphi(\|p_j - p_k\|)
\end{equation}
其中$\gamma > 0$控制协调强度。排斥核选取为：
\begin{equation}\label{eq:kernel}
\varphi(r) = \frac{1}{r + \epsilon}
\end{equation}
$\epsilon > 0$防止零间距处的奇异性。
该核函数单调递减，使$\Phi_j$在追逐者靠近时取大值、
分离后趋于零——恰好是阻止轨迹重叠所需的行为。
度归一化$1/d_j$确保协调强度不随组大小变化。

\subsection{增广值函数}

核心理论构造是\emph{增广值函数}，它分解为学习的追踪分量和解析的协调分量：
\begin{equation}\label{eq:vaug}
V_j^{\mathrm{aug}}(\tilde{x}_j, p_j, \{p_k\}) = \hat{W}_j^T\,\psi(\tilde{x}_j) + \Phi_j(p_j, \{p_k\})
\end{equation}
第一项$\hat{W}_j^T\psi(\tilde{x}_j)$由V-SNAC学习，编码个体追逃最优性；
第二项$\Phi_j$是解析的，编码团队协调目标。
这种分解具有若干重要性质。

增广值函数关于状态的梯度相应分解：
\begin{equation}\label{eq:grad_aug}
\nabla V_j^{\mathrm{aug}} = (\nabla \psi)^T \hat{W}_j + \nabla \Phi_j
\end{equation}
其中$\nabla \Phi_j$由核函数梯度计算：
\begin{equation}\label{eq:grad_phi}
\nabla_{p_j} \Phi_j = -\frac{\gamma}{d_j}\sum_{k:\,a_{jk}>0} \frac{p_j - p_k}{\|p_j - p_k\|(\|p_j - p_k\| + \epsilon)^2}
\end{equation}
该梯度通过输入矩阵结构(\ref{eq:g_struct})嵌入速度子空间。

\subsection{增广控制律}

\textit{追逐者最优控制}。
对增广Hamiltonian施加驻点条件$\partial H^{\mathrm{aug}}/\partial u_j^p = 0$得：
\begin{equation}\label{eq:ctrl_aug}
u_j^{p*} = -\bar{u}_p\,\tanh\!\bigg(\frac{1}{2\bar{u}_p}\,R_1^{-1}\,g_j^T\,\nabla V_j^{\mathrm{aug}}\bigg)
\end{equation}
由于$\Phi_j$不依赖于$u_j^p$，
变分结构与标准HJI情形完全一致：
$\partial H^{\mathrm{aug}}/\partial u_j^p = 0$产生相同的$\tanh$形式，
只是在增广梯度$\nabla V_j^{\mathrm{aug}}$而非$\nabla V_j^*$处求值。
学习的追踪梯度和解析的协调梯度在$\tanh$\emph{内部}叠加，
因此执行器饱和约束$\|u_j^{p*}\| \leq \bar{u}_p$自动满足。

当$\gamma = 0$或$d_j = 0$（单独追逐者）时，
$\Phi_j = 0$，式(\ref{eq:ctrl_aug})退化为基线(\ref{eq:ctrl_pursuer})。

\textit{逃逸者最坏情况控制}。
协调势$\Phi_j$仅依赖追逐者位置，不涉及任何逃逸者状态。
因此，逃逸者的控制问题不受协调层影响，最坏情况策略仍为：
\begin{equation}\label{eq:ctrl_evader_aug}
u_e^{*} = -\bar{u}_e\,\tanh\!\bigg(\frac{1}{2\bar{u}_e}\,R_2^{-1}\,g_e^T\,\nabla V_j^*\bigg)
\end{equation}
其中$\nabla V_j^*$仅为追踪值梯度。
这在物理上是直观的：逃逸者不知道也不关心追逐者之间如何协调，
它只是对每个个体追逃执行最坏情况策略。

\subsection{理论性质}

\textit{增广HJI方程}。
增广值函数$V_j^{\mathrm{aug}}$满足增广HJI方程，
其阶段代价在标准追踪代价之外还包含协调运行代价$\ell_\Phi$：
\begin{equation}\label{eq:aug_hji}
0 = \tilde{x}_j^T Q\,\tilde{x}_j + \ell_\Phi + (\nabla V_j^{\mathrm{aug}})^T [f_j + g_j u_j^{p*} - g_e u_e^*] + U(u_j^{p*}) - W(u_e^*)
\end{equation}
其中$\ell_\Phi = \dot{\Phi}_j - (\nabla \Phi_j)^T g_j u_j^{p*}$
吸收了势函数沿增广轨迹的时间导数。
这建立了增广控制关于修正代价（同时惩罚追踪误差和追逐者间近距）的最优性。

\textit{与基于势函数的奖励塑形的联系}。
分解(\ref{eq:vaug})是Ng等人\cite{b_ng1999}意义下的基于势函数的奖励塑形：
协调势$\Phi_j$仅依赖状态（追逐者位置），不依赖动作。
奖励塑形理论的经典结论表明，
向值函数添加状态相关势函数可以保持最优策略结构，
同时重新引导探索\cite{b_ng1999}。
在本文设定中，$\Phi_j$将追踪轨迹重新引导向空间多样性，
而不改变渐近追踪保证。

\textit{训练与执行分离}。
V-SNAC权重在$\gamma = 0$（纯追踪）下训练。
协调势仅在执行时引入。
这一分离保持了训练阶段的UUB收敛保证\cite{b_lewis1998}，
并允许运行时调整$\gamma$而无需重新训练。

\textit{通信丢失鲁棒性}。
$\mathcal{G}_p$中的边丢失使$d_j$和协调梯度成比例减小。
完全失联时$\nabla \Phi_j = 0$，恢复V-SNAC基线。
对于丢包率$p_d$的部分丢失，利用$\tanh$的Lipschitz性质（常数为1）：
\begin{equation}\label{eq:dropout}
\|u_j^{\text{full}} - u_j^{\text{drop}}\| \leq \frac{1}{2\bar{u}_p}\|R_1^{-1}\|\,\|G_v\|_\infty\,\|\nabla\Phi_j^{\text{full}} - \nabla\Phi_j^{\text{drop}}\|
\end{equation}
由于$\nabla \Phi_j$受$\gamma/\epsilon^2$界定，
控制扰动有界且正比于$\gamma$，确保平滑退化。

\section{实验与结果分析}
% =====================================================================

\subsection{实验设置}

仿真采用六自由度非线性飞行器模型，
状态$x = [p_x, p_y, h, v_x, v_y, v_h]^T$。
追逐者饱和$\bar{u}_p = 25$，逃逸者饱和$\bar{u}_e = 15$，
反映追逐者的速度优势。
每个V-SNAC critic使用式(\ref{eq:basis})中的6维多项式基函数，
训练50--56轮策略迭代，衰减学习率$\alpha_s = 0.05 \times 0.85^s$。
协调强度$\gamma = 0.3$，奇异防护$\epsilon = 0.1$。

五种团队配置：3追1、3追3、5追3、6追3、8追4，
覆盖追逐者/逃逸者比率1至3。
同一组训练权重分别在三种通信模式下评估：
全通信（$\gamma = 0.3$）、无通信（$\gamma = 0$）和
丢包通信（$\gamma = 0.3$，15\%丢包率）。
惩罚矩阵$Q = I_6$，$R_1 = 0.1 I_3$，$R_2 = 0.1 I_3$。

\subsection{协调有效性验证：受控场景}

为隔离协调势的作用，构造受控场景：
两个追逐者从相近位置出发，具有相同的指派目标和初始速度。
无协调时，两者的追踪误差和控制在每个时刻完全相同，轨迹完全重合。
该场景直接说明了多追逐者共享目标时独立最优控制的不足。

表~\ref{tab:results}汇总了五种配置在三种通信模式下的捕获时间，
呈现出若干规律。

在3追1场景（比率为3）中，协调势分散了接近路径，
捕获时间增加约8秒。
这反映了追踪激进性与空间多样性之间的固有权衡：
追逐者牺牲部分收敛速度以实现多方向包围，
在对抗环境中这是战术上更优的选择。

在6追3场景（比率为2）中，全通信模式实现了\emph{更快}的捕获
（36.6秒 vs 37.5秒基线）。
这一看似反直觉的结果源于：分散的接近角度减少了包围阶段的相互干扰，
使动态分配算法找到了更高效的指派方案。

3追3场景（比率为1）充当天然对照组：
每个逃逸者仅被一个追逐者追踪，
通信图无组内边（所有$j$的$d_j = 0$）。
三种模式结果完全一致（33.5秒），
验证了协调机制在无同组邻居时正确禁用。

15\%丢包下，捕获时间偏差均在0.3秒以内，
与式(\ref{eq:dropout})的有界扰动分析一致。

\section{结论}
% =====================================================================

本文提出了面向非线性追逃博弈的分层协同控制框架。
核心理论贡献是增广值函数，它分解为学习的追踪分量（通过V-SNAC）
和解析的协调势函数，两者梯度在$\tanh$饱和内组合得到追逐者控制。
逃逸者最坏情况控制仅由追踪值梯度推导，
因为协调势仅涉及追逐者状态。
增广公式满足增广HJI方程，并与基于势函数的奖励塑形理论建立了联系。

三层框架——个体V-SNAC控制、动态目标分配和基于通信的协调——
分别处理个体最优性、团队分配和组内空间多样性。
在非线性六自由度飞行器模型上覆盖五种团队配置的实验表明：
（一）协调势有效分离同组追逐者的空间轨迹；
（二）通信下捕获性能保持甚至改善；
（三）30\%丢包下平滑退化；
（四）无需协调时正确禁用。
后续工作将研究基于实时邻近度的自适应协调强度调度、
异构动力学的推广以及通信延迟的显式建模。
