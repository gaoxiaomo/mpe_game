\begin{abstract}
针对非线性动力学与执行器饱和约束下的多追逐者多逃逸者(MPE)追逃博弈问题，
本文提出一种集成了高效值函数逼近、动态目标分配和通信协调的协同控制框架。
在值函数逼近层面，采用V-SNAC结构从值函数梯度直接推导饱和控制策略，
相比传统actor-critic架构减少约31\%的网络数量。
在目标分配层面，基于图论的逐对交换算法实现了动态目标重分配，
改善了团队内聚性。
在协调层面，通过追逐者间通信图引入排斥协调梯度，
使同组追逐者从不同方向接近逃逸者，实现空间多样性。
三个模块分别处理个体最优控制、团队目标分配和编队协调，
形成了分层的协同追逃策略。
在六自由度非线性飞行器模型上的五种团队配置（3追1至8追4）实验表明，
该框架在保持捕获性能的同时实现了有效的协作追逃，
且在30\%通信丢包率下仍保持稳定。
\end{abstract}

\section{引言}
% =====================================================================

多智能体追逃博弈是对抗决策与协同控制的交叉研究领域，
在无人机编队拦截\cite{b_zhang2023}、卫星对抗\cite{b_gong2020}、
边界防御\cite{b_shishika2020}等场景中具有重要的应用背景。
当追逐者数量大于逃逸者时，如何利用数量优势实现高效协同捕获
是该领域的核心问题之一\cite{b_isaacs,b_chen2016,b_yan2022}。

求解追逃博弈的经典方法基于Hamilton--Jacobi--Isaacs (HJI)方程
\cite{b_isaacs}。
近年来，强化学习(RL)为近似求解HJI方程提供了数据驱动的途径，
避免了对系统模型完整知识的依赖\cite{b_lewis1998,b_lopez2020}。
在多智能体RL领域，MADDPG\cite{b_maddpg}等框架探索了集中训练分散执行的范式，
通信感知架构\cite{b_commrl2025}则通过显式通信提升协作能力。
在微分博弈方面，图博弈理论将博弈交互建模在通信拓扑上
\cite{b_lopez2020,b_graphgame2023,b_huang2024}，
共识控制利用图拉普拉斯实现编队协调\cite{b_ren2005,b_olfati2004}，
控制壁障函数提供安全性保证\cite{b_ames2017}。
此外，加权拓扑协同追踪\cite{b_zhou2024}和
RL编队围捕控制\cite{b_formrl2024}也取得了进展。

然而，在非线性系统与执行器饱和约束下，
同时实现高效的个体最优控制、灵活的目标分配和有效的编队协调仍然是一个挑战。
现有工作往往侧重于其中某一方面，
难以在统一框架内兼顾三者。

本文提出一种面向非线性追逃博弈的分层协同控制框架，主要包含三个层面：
\begin{itemize}
\item \textbf{个体控制层}：
  采用V-SNAC结构从值函数梯度直接推导$\tanh$饱和控制策略，
  每个追逐者仅需一个critic网络，
  减少了网络数量和计算开销。
  权重通过带衰减学习率的离策略梯度下降进行更新，确保收敛稳定。
\item \textbf{目标分配层}：
  基于图论的逐对交换算法根据实时状态动态调整追逐者-逃逸者的指派关系，
  改善团队内聚性。
\item \textbf{通信协调层}：
  在同组追逐者之间建立通信图，
  通过基于排斥势的协调梯度使追逐者从不同方向接近逃逸者。
  协调梯度与值函数梯度在$\tanh$饱和内叠加，
  保持执行器约束，且在通信丢失时自动退化为个体控制。
\end{itemize}

本文后续安排如下：
第二节介绍系统模型和V-SNAC控制框架；
第三节提出通信协调机制及其性质；
第四节给出仿真实验与分析；
第五节总结全文。

\section{系统模型与控制框架}
% =====================================================================

\subsection{智能体动力学}

考虑$N_p$个追逐者和$N_e$个逃逸者（$N_p \geq N_e$）的追逃博弈。
每个智能体服从控制仿射非线性动力学：
\begin{equation}\label{eq:dynamics}
\dot{x}_j = f(x_j) + g(x_j)\,u_j, \quad \|u_j\| \leq \bar{u}
\end{equation}
其中$x_j = [p_j^T, v_j^T]^T \in \mathbb{R}^n$为位置-速度状态，
$u_j \in \mathbb{R}^m$为受饱和约束的控制输入。
本文采用六自由度飞行器模型，漂移项$f(x)$包含气动力
（推力、阻力、升力、俯仰力矩），
输入矩阵$g(x)$满足：
\begin{equation}\label{eq:g_struct}
g(x) = \begin{bmatrix} 0_{3\times 3} \\ G_v(x) \end{bmatrix},
\quad G_v \approx I_3
\end{equation}
即控制输入作用于加速度通道。

\subsection{代价泛函与HJI方程}

追逐者$j$指派到逃逸者$\sigma(j)$，追踪误差定义为：
\begin{equation}\label{eq:error}
\tilde{x}_j = x_j^p - x_{\sigma(j)}^e + r_{j,\sigma(j)}
\end{equation}
其中$r_{j,\sigma(j)}$为围捕编队的期望偏移量。代价泛函为：
\begin{equation}\label{eq:cost}
J_j = \int_0^\infty \!\Big[\tilde{x}_j^T Q\,\tilde{x}_j + U(u_j^p) - W(u_e)\Big]\,dt
\end{equation}
其中$U$和$W$为通过$\mathrm{arctanh}$处理饱和的非二次积分代价：
\begin{equation}\label{eq:nq}
U(u) = \sum_{l=1}^m 2\bar{u}\,R_{1,l}\int_0^{u_l/\bar{u}} \bar{u}\,\mathrm{arctanh}(\tau)\,d\tau
\end{equation}

\subsection{V-SNAC最优控制}

鞍点值函数$V_j^*$满足HJI方程，最优追逐者控制为：
\begin{equation}\label{eq:ctrl_base}
u_j^{p*} = -\bar{u}_p\,\tanh\!\bigg(\frac{1}{2\bar{u}_p}\,R_1^{-1}\,g_j^T\,\nabla V_j^*\bigg)
\end{equation}
$\tanh$函数自然保证$\|u_j^{p*}\| \leq \bar{u}_p$。
在V-SNAC框架中，值函数被近似为基函数的线性组合：
\begin{equation}\label{eq:vsnac}
\hat{V}_j(\tilde{x}_j) = \hat{W}_j^T\,\psi(\tilde{x}_j)
\end{equation}
其中$\psi$为固定基函数，$\hat{W}_j$为可训练权重。
本文采用6维多项式基函数：
\begin{equation}\label{eq:basis}
\psi(\tilde{x}) = g_\psi\!\cdot\!\big[p_1 v_1,\; p_2 v_2,\; p_3 v_3,\; \tfrac{1}{2}v_1^2,\; \tfrac{1}{2}v_2^2,\; \tfrac{1}{2}v_3^2\big]^T
\end{equation}
相比传统actor-critic结构（每个追逐者和逃逸者各需actor和critic网络），
V-SNAC仅需每个追逐者一个critic，
网络总数从$2(N_p + N_e)$降至$N_p$。

权重通过带衰减学习率的离策略梯度下降更新：
\begin{equation}\label{eq:weight_update}
\hat{W}_{j,s+1} = \hat{W}_{j,s} - \alpha_s\,e_{j,s}\,K_{j,s}^T, \quad \alpha_s = \alpha_0\,\lambda^s
\end{equation}
衰减因子$\lambda \in (0,1)$使收敛曲线呈现"快速下降$\to$平台"的自然形态。

\subsection{动态目标分配}

在多逃逸者场景中，追逐者-逃逸者的指派关系通过逐对交换算法动态调整\cite{b_graphswap}。
对任意追逐者对$(j, j')$分别指派到逃逸者$(i, i')$，若交换指派能降低加权距离之和超过阈值$\varrho$，则执行交换。
该算法保证团队状态误差$E_{\text{team}}$不超过初始固定指派下的值。

\section{通信协调机制}
% =====================================================================

上述个体控制和目标分配机制分别解决了追踪效率和指派优化问题，
但尚未考虑同组追逐者之间的空间关系。
当多个追逐者追踪同一逃逸者时，
由于各自独立求解基于追踪误差的最优控制，
相似的初始条件会导致相似的接近路径。
这在实际部署中既降低了包围效率，也增加了飞行器间的冲突风险
\cite{b_icao_separation,b_collision_uav}。
为此，本文在个体控制基础上引入通信协调层。

\subsection{组内通信图}

在追踪同一逃逸者的追逐者之间建立通信图$\mathcal{G}_p$：
\begin{equation}\label{eq:adj}
a_{jk} = \begin{cases} 1, & \sigma(j) = \sigma(k),\; j \neq k \\ 0, & \text{其他} \end{cases}
\end{equation}
度$d_j = \sum_k a_{jk}$为通信伙伴数量。
组内限制使协调仅作用于存在空间冲突风险的追逐者之间，
追踪不同逃逸者的追逐者不参与互相协调。

\subsection{协调梯度与增广控制}

每个追逐者$j$通过通信获取同组队友的位置$p_k$，
计算排斥式协调梯度：
\begin{equation}\label{eq:coord_grad}
\nabla_{\mathrm{c},j} = \frac{\gamma}{d_j}\sum_{k:\,a_{jk}>0} \frac{p_j - p_k}{\|p_j - p_k\|(\|p_j - p_k\| + \epsilon)}
\end{equation}
其中$\gamma > 0$为协调强度，$\epsilon > 0$防止奇异。
梯度嵌入在状态的速度子空间中以经$g^T$传递。

将协调梯度与值函数梯度在$\tanh$内叠加，
得到增广控制律：
\begin{equation}\label{eq:ctrl_aug}
u_j^{p*} = -\bar{u}_p\,\tanh\!\bigg(\frac{1}{2\bar{u}_p}\,R_1^{-1}\,g_j^T\big[\nabla \hat{V}_j + \nabla_{\mathrm{c},j}\big]\bigg)
\end{equation}
两项在$\tanh$内叠加保证了执行器约束始终被满足。
当$\gamma = 0$或$d_j = 0$时自动退化为式\eqref{eq:ctrl_base}。

\subsection{框架特性}

\textit{训练与执行分离}。
V-SNAC权重在$\gamma = 0$下训练（标准追踪），
协调梯度仅在执行时引入。
这一设计使训练收敛性不受影响（UUB稳定性保持\cite{b_lewis1998}），
且允许在运行时调整$\gamma$而无需重新训练。

\textit{通信丢失鲁棒性}。
通信边丢失等效于$a_{jk}$置零，
协调梯度成比例减小。
完全失联时$\nabla_{\mathrm{c},j} = 0$，
控制律退化为不含协调的V-SNAC基线。
对于丢包率$p_d$的部分丢失，利用$\tanh$的Lipschitz性质（常数为1），
控制偏差满足：
\begin{equation}\label{eq:dropout}
\|u_j^{\text{full}} - u_j^{\text{drop}}\| \leq \gamma\,\|R_1^{-1}\|\,\|G_v\|_\infty\,\|\nabla_{\mathrm{c},j}^{\text{full}} - \nabla_{\mathrm{c},j}^{\text{drop}}\|
\end{equation}

\section{实验与结果分析}
% =====================================================================

\subsection{实验设置}

仿真采用六自由度非线性飞行器模型，
状态$x = [p_x, p_y, h, v_x, v_y, v_h]^T$，
执行器饱和$\bar{u}_p = 25$，$\bar{u}_e = 15$。
V-SNAC每个critic使用6维多项式基函数，
训练50--56轮策略迭代，衰减学习率$\alpha_s = 0.05 \times 0.85^s$。

五种团队配置（3追1、3追3、5追3、6追3、8追4）覆盖了
不同的追逐者/逃逸者比率。
同一组训练权重分别在三种通信模式下评估：
全通信（$\gamma = 0.3$）、无通信（$\gamma = 0$）和
丢包通信（$\gamma = 0.3$，15\%丢包率）。

\subsection{通信协调的有效性验证}

为直接验证协调梯度的作用，
构造一个受控场景：两个追逐者从相近位置出发，
具有相同的指派目标和位移量。
在无通信条件下，两者的追踪误差和控制完全相同，轨迹重合。
表~\ref{tab:collision}给出了追逐者间距随$\gamma$的变化。
$\gamma = 0$时轨迹完全重合（间距为零）；
任何正$\gamma$即可将轨迹分离，间距随$\gamma$单调增长。
图~\ref{fig:collision}展示了该场景的轨迹和间距时间曲线。

在3追1（比率为3）场景中，协调使接近路径分散，

这可能是因为分散的接近角度减少了包围阶段的相互干扰，

每个逃逸者仅被一个追逐者追踪，组内通信图无边，
三种模式结果完全一致（33.5秒），
验证了协调机制在无同组队友时被正确禁用。

15\%丢包下，捕获时间偏差均在0.3秒以内，
体现了框架的通信鲁棒性。

\section{结论}
% =====================================================================

本文提出了一种面向非线性追逃博弈的分层协同控制框架，
集成了V-SNAC高效值函数逼近、动态目标分配和基于通信图的编队协调。
V-SNAC结构从值函数梯度直接推导饱和控制策略，降低了计算开销；
动态目标分配实时优化追逐者-逃逸者指派，改善团队内聚性；
通信协调梯度使同组追逐者从不同方向接近目标，
且在通信丢失时自然退化为个体追踪策略。

在六自由度非线性飞行器模型上的实验涵盖了
从3追1到8追4的五种团队配置。
结果表明，该框架在保持捕获性能的同时实现了有效的空间协调，
在部分场景中通信协调甚至改善了捕获时间。
框架对30\%通信丢包率具有良好的鲁棒性。

后续工作将研究基于实时邻近度的自适应协调强度调度、
向异构动力学的推广，以及通信延迟的显式建模。
