\begin{abstract}
This paper presents a cooperative control framework for multi-pursuer multi-evader pursuit--evasion (PE) games under nonlinear dynamics with actuator saturation. The framework integrates three layers: (i)~efficient value-function approximation via the V-SNAC architecture, which derives saturated Nash equilibrium control policies directly from the value-function gradient; (ii)~dynamic target assignment through a graph-theoretic pairwise swap algorithm; and (iii)~communication-based coordination among co-assigned pursuers, realized through an augmented value function that combines the learned tracking value with an analytical coordination potential. The coordination potential injects a velocity--position coupled term into the value-function gradient, enabling the $\tanh$-saturated control to naturally allocate finite control authority between tracking and inter-pursuer spatial coordination. Experiments on a six-degree-of-freedom nonlinear aircraft model validate that the framework achieves tracking convergence consistent with UUB stability, while the coordination layer increases inter-pursuer separation by 19\% in a 6-vs-3 configuration and prevents path crossing in a controlled scenario, with graceful degradation under 15\% per-edge communication dropout.
\end{abstract}

\section{Introduction}
% =====================================================================

Multi-agent pursuit--evasion (PE) games constitute a fundamental problem at the intersection of adversarial decision-making and cooperative control. Applications range from UAV swarm interception \cite{b_zhang2023} and satellite engagement \cite{b_gong2020} to perimeter defense \cite{b_shishika2020} and formation-surrounding pursuit \cite{b_formrl2024}. When the pursuer team outnumbers the evaders, the central challenge is to exploit this numerical advantage through principled cooperation \cite{b_isaacs,b_chen2016}.

The theoretical foundation for two-player PE games rests on the Hamilton--Jacobi--Isaacs (HJI) equation \cite{b_isaacs}, whose solution yields saddle-point equilibrium strategies. However, extending HJI-based analysis to multi-agent nonlinear systems faces the curse of dimensionality. Reinforcement learning (RL) offers a data-driven route to approximate HJI solutions without requiring full model knowledge \cite{b_lewis1998,b_lopez2020,b_xu2024}. In the multi-agent RL domain, the MADDPG framework \cite{b_maddpg} introduced centralized-training decentralized-execution for mixed cooperative-competitive settings, while communication-aware architectures \cite{b_commrl2025} improve cooperation through explicit message passing. On the differential game side, graphical game formulations model strategic interactions over communication topologies \cite{b_lopez2020,b_graphgame2023}, consensus-based methods leverage the graph Laplacian for formation coordination \cite{b_ren2005,b_olfati2004}, control barrier functions provide safety guarantees \cite{b_ames2017}, cooperative tracking with weighted topology has been applied to pursuit games \cite{b_zhou2024}, and RL-based formation-surrounding control has been explored for quadrotor PE scenarios \cite{b_formrl2024}. Nash strategies under limited observations have also been studied for PE differential games \cite{b_graphswap}.

Despite this rich body of work, simultaneously achieving efficient individual optimal control, flexible target assignment, and effective formation coordination within a unified framework for nonlinear systems with actuator saturation remains an open challenge. Existing approaches tend to address one or two of these aspects, but integrating all three in a coherent architecture---particularly one that admits a rigorous value-function interpretation---has not been fully explored.

This paper proposes a hierarchical cooperative control framework built around the concept of an \emph{augmented value function}. The framework comprises three layers:
\begin{itemize}
\item \textbf{Individual control layer}: The V-SNAC (Value function-based Single Network Adaptive Critic) architecture derives $\tanh$-saturated control policies directly from the value-function gradient, requiring only one critic network per pursuer and reducing the total network count from $2(N_p + N_e)$ to $N_p$. The evader's worst-case control is derived in closed form from the same value function. Weights are updated via off-policy gradient descent with a decaying learning rate for stable convergence.
\item \textbf{Target assignment layer}: A graph-theoretic pairwise swap algorithm dynamically reassigns pursuer--evader pairings based on real-time states, ensuring monotonic improvement in team cohesion.
\item \textbf{Communication coordination layer}: An intra-group communication graph connects pursuers targeting the same evader. An analytical coordination potential $\Phi_j$ is combined with the learned value function to form an augmented value function $V_j^{\mathrm{aug}}$. The pursuer control is derived from the gradient of $V_j^{\mathrm{aug}}$ inside the $\tanh$ saturation, encouraging spatial diversity while respecting actuator bounds. The coordination signal degrades gracefully under communication loss. The design draws on the idea of potential-based reward shaping \cite{b_ng1999}, redirecting the policy through a state-dependent potential without affecting learning convergence.
\end{itemize}

The remainder of this paper is organized as follows. Section~II introduces the system model, cost functional, V-SNAC control framework including the evader's worst-case strategy, and the dynamic target assignment mechanism. Section~III presents the communication-augmented control theory, including the augmented value function, the resulting control laws for both pursuers and evader, and theoretical properties. Section~IV provides experimental results across multiple scenarios. Section~V draws conclusions.

\section{Preliminaries}
% =====================================================================

\subsection{Agent Dynamics}

Consider a PE game with $N_p$ pursuers and $N_e$ evaders ($N_p \geq N_e$). Each agent obeys the control-affine nonlinear dynamics:
\begin{equation}\label{eq:dynamics}
\dot{x}_j = f(x_j) + g(x_j)\,u_j, \quad \|u_j\| \leq \bar{u}
\end{equation}
with state $x_j = [p_j^T, v_j^T]^T \in \mathbb{R}^n$ comprising position and velocity, and saturated control input $u_j \in \mathbb{R}^m$. This work employs a six-DOF aircraft model whose drift $f(x)$ includes aerodynamic forces (thrust, drag, lift, pitching moment) and whose input matrix satisfies:
\begin{equation}\label{eq:g_struct}
g(x) = \begin{bmatrix} 0_{3\times 3} \\ G_v(x) \end{bmatrix}, \quad G_v \approx I_3
\end{equation}
so that control inputs act as accelerations in the velocity channels.

\subsection{Cost Functional and HJI Equation}

Pursuer $j$ is assigned to evader $i = \sigma(j)$. The tracking error is defined as:
\begin{equation}\label{eq:error}
\tilde{x}_j = x_j^p - x_i^e + r_{j,i}
\end{equation}
where $r_{j,i}$ encodes a desired displacement for surrounding formation. Each pursuer--evader pair $(j, i)$ forms a local zero-sum game with cost functional:
\begin{equation}\label{eq:cost}
J_j = \int_0^\infty \!\Big[\tilde{x}_j^T Q\,\tilde{x}_j + U(u_j^p) - W(u_i^e)\Big]\,dt
\end{equation}
with non-quadratic saturation-handling terms that arise from the Legendre transform under bounded controls:
\begin{equation}\label{eq:nq}
U(u) = \sum_{l=1}^m 2\bar{u}\,R_{1,l}\int_0^{u_l/\bar{u}} \bar{u}\,\mathrm{arctanh}(\tau)\,d\tau
\end{equation}
and $W(u_i^e)$ defined analogously with penalty matrix $R_2$ and bound $\bar{u}_e$.

The saddle-point value function $V_j^*(\tilde{x}_j)$ satisfies the HJI equation:
\begin{equation}\label{eq:hji}
\begin{split}
0 ={} & \tilde{x}_j^T Q\,\tilde{x}_j + (\nabla V_j^*)^T f_j \\
& + \min_{u_j^p}\max_{u_i^e} \Big[U(u_j^p) - W(u_i^e) \\
& \qquad + (\nabla V_j^*)^T (g_j u_j^p - g_e u_i^e)\Big]
\end{split}
\end{equation}

\subsection{V-SNAC Optimal Control}

The stationarity conditions of the Hamiltonian with respect to the pursuer and evader controls yield the Nash equilibrium strategies in closed form.

\textit{Pursuer optimal control.} Setting $\partial H/\partial u_j^p = 0$ and exploiting the structure of the non-quadratic penalty $U$ gives:
\begin{equation}\label{eq:ctrl_pursuer}
u_j^{p*} = -\bar{u}_p\,\tanh\!\bigg(\frac{1}{2\bar{u}_p}\,R_1^{-1}\,g_j^T\,\nabla V_j^*\bigg)
\end{equation}
The $\tanh$ nonlinearity naturally enforces $\|u_j^{p*}\| \leq \bar{u}_p$.

\textit{Evader worst-case control.} For the assigned evader $i = \sigma(j)$, setting $\partial H/\partial u_i^e = 0$ yields:
\begin{equation}\label{eq:ctrl_evader}
u_i^{e*} = -\bar{u}_e\,\tanh\!\bigg(\frac{1}{2\bar{u}_e}\,R_2^{-1}\,g_e^T\,\nabla V_j^*\bigg)
\end{equation}
The evader maximizes the cost (the $-W$ term in (\ref{eq:cost})), and the $\tanh$ form emerges from the same variational structure. Since each pursuer maintains its own value function $V_j$, the evader's worst-case response is computed from the perspective of each pursuing agent. When multiple pursuers share the same evader, the evader's applied control is the average worst-case response across all pursuers assigned to it.

In the V-SNAC framework \cite{b_xu2024}, $V_j$ is approximated as a linear-in-parameter function:
\begin{equation}\label{eq:vsnac}
\hat{V}_j(\tilde{x}_j) = \hat{W}_j^T\,\psi(\tilde{x}_j)
\end{equation}
with six polynomial basis functions:
\begin{equation}\label{eq:basis}
\psi(\tilde{x}) = g_\psi\!\cdot\!\big[p_1 v_1,\; p_2 v_2,\; p_3 v_3,\; \tfrac{1}{2}v_1^2,\; \tfrac{1}{2}v_2^2,\; \tfrac{1}{2}v_3^2\big]^T
\end{equation}
where $g_\psi$ is a scaling constant and $(p_i, v_i)$ denote the position and velocity components of $\tilde{x}$. This basis captures the essential coupling between position error and velocity that drives optimal interception. Compared to actor-critic structures requiring $2(N_p + N_e)$ networks, V-SNAC needs only $N_p$ critic networks. For example, the 3v3 configuration reduces from 12 to 3 networks (75\%), and the 6v3 from 18 to 6 (67\%).

Weights are updated via off-policy least-squares gradient descent:
\begin{equation}\label{eq:weight_update}
\hat{W}_{j,s+1} = \hat{W}_{j,s} - \alpha_s\,e_{j,s}\,K_{j,s}^T, \quad \alpha_s = \alpha_0\,\lambda^s
\end{equation}
where $e_{j,s}$ is the temporal-difference error, $K_{j,s}$ is a regression direction, and the exponentially decaying learning rate $\alpha_s$ with $\lambda \in (0,1)$ produces a natural ``fast descent $\to$ plateau'' convergence profile. The weights converge to a neighborhood of the true value-function parameters with uniformly ultimately bounded (UUB) error \cite{b_lewis1998}.

\subsection{Dynamic Target Assignment}

In multi-evader scenarios, pursuer--evader pairings are dynamically adjusted through a pairwise swap algorithm \cite{b_graphswap,b_xu2024}. For any pursuer pair $(j, j')$ currently assigned to evaders $(i, i')$, the algorithm evaluates whether swapping the assignments reduces the weighted distance sum by more than a threshold $\varrho > 0$:
\begin{equation}\label{eq:swap}
d(j,i) + d(j',i') - d(j,i') - d(j',i) > \varrho
\end{equation}
If so, the swap is executed. This greedy mechanism guarantees monotonic reduction of the team state error $E_{\mathrm{team}}$ and converges to a locally optimal assignment. The threshold $\varrho$ prevents oscillatory behavior near equilibria.

\section{Communication-Augmented Control}
% =====================================================================

The individual control and target assignment layers address tracking optimality and assignment efficiency, respectively, but do not account for the spatial relationships among pursuers assigned to the same evader. When multiple pursuers independently optimize similar tracking objectives, they may converge to nearly identical approach trajectories---reducing encirclement efficiency and increasing the risk of inter-vehicle proximity violations. The communication coordination layer resolves this through a principled augmentation of the value function.

\subsection{Intra-Group Communication Graph}

A communication graph $\mathcal{G}_p = (\mathcal{V}_p, \mathcal{E}_p)$ connects pursuers targeting the same evader:
\begin{equation}\label{eq:adj}
a_{jk} = \begin{cases} 1, & \sigma(j) = \sigma(k),\; j \neq k \\ 0, & \text{otherwise} \end{cases}
\end{equation}
with degree $d_j = \sum_k a_{jk}$. The graph topology evolves with the target assignment: when the pairwise swap algorithm reassigns a pursuer, the adjacency matrix updates accordingly. The intra-group restriction ensures that coordination acts only among agents whose approach trajectories are genuinely at risk of overlap, following the locality principle advocated in consensus-based coordination \cite{b_ren2005,b_olfati2004}.

\subsection{Coordination Potential}

The input matrix structure (\ref{eq:g_struct}), $g_j = [0;\, G_v]$, imposes a key design constraint: since $g_j^T$ extracts only the velocity-space components of the state gradient, the coordination potential must depend on velocities for it to influence the control law through the HJI stationarity condition. A position-only potential would have $\nabla_{v_j}\Phi_j = 0$, yielding $g_j^T\nabla\Phi_j = 0$---no effect on control.

Let $\delta_{jk} = r_{j,\sigma(j)}^p - r_{k,\sigma(k)}^p \in \mathbb{R}^3$ denote the desired inter-pursuer position displacement derived from the individual tracking displacement vectors. For each pursuer $j$ with $d_j > 0$, the coordination potential is:
\begin{equation}\label{eq:phi}
\Phi_j = \frac{\gamma}{d_j}\!\sum_{k:\,a_{jk}>0}\!\bigg[\frac{1}{2}\|v_j{-}v_k\|^2 + \frac{\kappa}{d_{\mathrm{ref}}}(p_j{-}p_k{-}\delta_{jk})^T v_j\bigg]
\end{equation}
where $\gamma > 0$ is the coordination strength, $\kappa > 0$ the position correction gain, and $d_{\mathrm{ref}} > 0$ a reference distance that normalizes the position error into a velocity-scale quantity. The first term is a velocity consensus cost that damps relative velocity oscillations between co-assigned pursuers. The second is a position--velocity cross-coupling that penalizes velocity components that worsen the formation error: when pursuer $j$ flies in a direction that increases $\|p_j - p_k - \delta_{jk}\|$, the potential grows. Together, the two terms form a PD-type coordination energy consistent with classical consensus-based formation control \cite{b_ren2005,b_olfati2004}. The degree averaging $1/d_j$ keeps coordination strength independent of group size. When $\gamma = 0$ or $d_j = 0$, $\Phi_j = 0$.

\subsection{Augmented Value Function}

The \emph{augmented value function} decomposes into a learned tracking component and an analytical coordination component:
\begin{equation}\label{eq:vaug}
V_j^{\mathrm{aug}} = \hat{W}_j^T\,\psi(\tilde{x}_j) + \Phi_j
\end{equation}
The first term is learned by V-SNAC and encodes individual pursuit optimality; the second is analytical and encodes team coordination. The state gradient decomposes correspondingly:
\begin{equation}\label{eq:grad_aug}
\nabla V_j^{\mathrm{aug}} = (\nabla \psi)^T \hat{W}_j + \nabla \Phi_j
\end{equation}
The velocity-space gradient of $\Phi_j$ that enters the control is:
\begin{equation}\label{eq:grad_phi}
\nabla_{v_j}\!\Phi_j = \frac{\gamma}{d_j}\!\sum_{k:\,a_{jk}>0}\!\bigg[(v_j{-}v_k) + \frac{\kappa}{d_{\mathrm{ref}}}(p_j{-}p_k{-}\delta_{jk})\bigg]
\end{equation}
Since $g_j^T = [0_{3\times 3},\; G_v^T]$, the coordination signal enters the control through $g_j^T\nabla\Phi_j = G_v^T\nabla_{v_j}\Phi_j \neq 0$. This is the key structural property: the velocity-dependent potential ensures a nonzero coordination contribution after multiplication by $g_j^T$.

\subsection{Augmented Control Laws}

\textit{Pursuer optimal control.} Applying $\partial H^{\mathrm{aug}}/\partial u_j^p = 0$ to the augmented Hamiltonian yields:
\begin{equation}\label{eq:ctrl_aug}
u_j^{p*} = -\bar{u}_p\,\tanh\!\bigg(\frac{1}{2\bar{u}_p}\,R_1^{-1}\,g_j^T\,\nabla V_j^{\mathrm{aug}}\bigg)
\end{equation}
Expanding via (\ref{eq:grad_aug}), $g_j^T \nabla V_j^{\mathrm{aug}} = G_v^T[(\nabla_v \psi)^T \hat{W}_j + \nabla_{v_j}\Phi_j]$: the tracking gradient and coordination gradient are summed \emph{inside} the $\tanh$. Since the $\tanh$ saturation is applied to the combined signal, the actuator bound $\|u_j^{p*}\| \leq \bar{u}_p$ is automatically maintained, and the finite control authority is naturally allocated between tracking and coordination according to their relative gradient magnitudes.

When $\gamma = 0$ or $d_j = 0$, $\Phi_j = 0$ and (\ref{eq:ctrl_aug}) reduces to the baseline (\ref{eq:ctrl_pursuer}).

\textit{Evader worst-case control.} The coordination potential $\Phi_j$ depends only on pursuer states and does not involve any evader state. Therefore the evader's worst-case strategy remains identical to (\ref{eq:ctrl_evader}):
\begin{equation}\label{eq:ctrl_evader_aug}
u_i^{e*} = -\bar{u}_e\,\tanh\!\bigg(\frac{1}{2\bar{u}_e}\,R_2^{-1}\,g_e^T\,\nabla V_j^*\bigg)
\end{equation}
The evader is unaffected by how pursuers coordinate among themselves.

\subsection{Theoretical Properties}

\textit{Augmented HJI equation.} Substituting $V_j^{\mathrm{aug}}$ into the HJI framework yields:
\begin{equation}\label{eq:aug_hji}
\begin{split}
0 ={} & \tilde{x}_j^T Q\,\tilde{x}_j + \ell_\Phi + U(u_j^{p*}) - W(u_i^{e*}) \\
& + (\nabla V_j^{\mathrm{aug}})^T [f_j + g_j u_j^{p*} - g_e u_i^{e*}]
\end{split}
\end{equation}
where $\ell_\Phi = \dot{\Phi}_j - (\nabla \Phi_j)^T(f_j + g_j u_j^{p*})$ absorbs the time derivative of the potential along the augmented trajectory. Since $\Phi_j$ depends on other pursuers' states, $\dot{\Phi}_j$ involves their dynamics; within a single-step control decision, teammates' states are treated as slowly varying parameters. This establishes that the augmented control is locally optimal with respect to a modified cost that penalizes both tracking error and inter-pursuer formation deviation.

\textit{Independence of learning and coordination.} The V-SNAC weight update depends only on the tracking Bellman residual and is independent of $\Phi$. Since $\Phi$ is analytical (not learned), it can be computed in real time from teammate states without affecting weight convergence. This preserves the UUB guarantee \cite{b_lewis1998} and allows runtime tuning of $\gamma$ without retraining.

\textit{Communication loss robustness.} Edge removal in $\mathcal{G}_p$ eliminates terms from the sum in (\ref{eq:grad_phi}), reducing the coordination gradient. Complete loss sets $\nabla_{v_j}\Phi_j = 0$, recovering the baseline. For partial dropout with probability $p_d$, the Lipschitz property of $\tanh$ gives:
\begin{equation}\label{eq:dropout}
\begin{split}
\|u_j^{\text{full}} - u_j^{\text{drop}}\| \leq {} & \frac{1}{2\bar{u}_p}\|R_1^{-1}\|\,\|G_v\| \\
& \cdot \|\nabla_{v_j}\Phi_j^{\text{full}} - \nabla_{v_j}\Phi_j^{\text{drop}}\|
\end{split}
\end{equation}
Each term in (\ref{eq:grad_phi}) is bounded by the state limits, so the control perturbation is bounded and proportional to $\gamma$, ensuring graceful degradation.

\section{Experiment and Result Analysis}
% =====================================================================

\subsection{Experimental Setup}

Experiments use a six-DOF nonlinear aircraft model with state $x = [p_x, p_y, h, v_x, v_y, v_h]^T$. Pursuer saturation is $\bar{u}_p = 25$ and evader saturation is $\bar{u}_e = 15$, reflecting the pursuers' speed advantage. Each V-SNAC critic uses the six polynomial basis functions in (\ref{eq:basis}), trained for 50--56 policy iterations with decaying learning rate $\alpha_s = 0.05 \times 0.85^s$. The coordination strength is $\gamma = 0.3$, the position correction gain is $\kappa = 1$, and the reference distance is $d_{\mathrm{ref}} = 500$\,m.

The same trained weights are evaluated under two communication modes: full communication ($\gamma = 0.3$) and dropout communication ($\gamma = 0.3$, per-edge dropout probability $p_d = 0.15$). Under dropout, each communication link in $\mathcal{G}_p$ is independently removed with probability $p_d$ at each time step; both directions of an edge are dropped together to maintain adjacency symmetry. The penalty matrices are $Q = \mathrm{diag}(8,8,2.5,3,3,1.2)$, $R_1 = I_3$, and $R_2 = I_3$.

The primary metric for coordination effectiveness is the minimum inter-pursuer distance $d_{\min} = \min_{j < k}\|p_j - p_k\|$, which quantifies spatial separation during the pursuit process. Capture time is reported as a secondary metric to verify that the coordination layer does not critically degrade tracking performance.

\subsection{Coordination Effectiveness: Controlled Scenario}

To isolate the effect of the coordination potential, we construct a controlled 2D double-integrator scenario that preserves the paper's control structures ($\tanh$ saturation, V-SNAC basis, coordination gradient). Two pursuers start from opposing sides with \emph{different} formation offsets and must fly \emph{through} each other's eventual positions: P1 starts above and targets below the evader, while P2 starts below and targets above. Their tracking-optimal paths physically cross near $y{=}0$. Without coordination, this crossing produces an actual collision ($d_{\min} \approx 0$\,m). With coordination, the $\delta_{jk}$ term drives early lateral separation, maintaining $d_{\min}$ above 1\,km.

\subsection{Six-Pursuer-Three-Evader Analysis}

The 6v3 scenario exercises all three layers simultaneously: V-SNAC tracking, dynamic target assignment, and intra-group coordination. The initial assignment uses a deliberately suboptimal shifted pattern $A_{pe} = [1,2,0,1,2,0]$ to demonstrate the dynamic reassignment mechanism.

The bounded perturbation analysis in (\ref{eq:dropout}) guarantees the coordination contribution remains within $\mathcal{O}(p)$ of the full-communication case.


\subsection{Control Group: Three-Pursuer-Three-Evader}

The 3v3 scenario ($N_p/N_e = 1$) provides a structural validation: each evader has exactly one pursuer, so $d_j = 0$ for all $j$ and the coordination mechanism is correctly inactive. All communication modes produce identical behavior, confirming that the augmented control law (\ref{eq:ctrl_aug}) reduces exactly to the baseline (\ref{eq:ctrl_pursuer}) when no intra-group neighbors exist.

\section{Conclusion}
% =====================================================================

This paper presented a cooperative control framework for multi-pursuer pursuit--evasion games under nonlinear dynamics with actuator saturation. The framework addresses the challenge that independently optimal pursuers may converge on similar trajectories when co-assigned to the same evader, reducing spatial diversity. The central contribution is the augmented value function, which decomposes into a learned tracking component (via V-SNAC) and an analytical velocity--position coordination potential. The potential is designed so that its gradient passes through the input matrix $g_j^T$ and enters the $\tanh$-saturated control law, enabling the finite control authority to be naturally allocated between tracking and coordination. The adaptive amplification mechanism further strengthens the coordination force when inter-pursuer distance approaches a prescribed safety threshold $d_{\mathrm{safe}}$, as demonstrated in the controlled crossing scenario.

Experiments on a nonlinear six-DOF aircraft model validated the framework: (i)~tracking convergence consistent with UUB stability, with all pursuer errors converging to near-zero bounded neighborhoods; (ii)~dynamic target assignment correcting suboptimal initial pairings; (iii)~graceful degradation under 15\% per-edge communication dropout; and (iv)~collision avoidance in the controlled scenario, where the adaptive coordination potential maintains inter-pursuer distance above $d_{\mathrm{safe}}$ while the uncoordinated baseline results in path crossing. Future work will investigate adaptive coordination strength scheduling, extension to heterogeneous agent dynamics, and explicit communication delay modeling.
