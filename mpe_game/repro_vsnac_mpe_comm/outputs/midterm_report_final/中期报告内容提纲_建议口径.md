# 中期报告内容提纲与建议口径

## 总体写法

- 这份中期报告不要写成“全面优于已有方法”的叙事。
- 更稳妥的主线是：
  - 已完成一个可运行、可复现实验的多智能体追逃近似最优控制框架；
  - 在此基础上加入了解析通信协调项和平滑因子；
  - 在通用场景下，该扩展**基本不破坏原有追踪性能**；
  - 在专门构造的多对多危险交叉场景下，该扩展能**明显降低近距离交叉风险**；
  - 目前仍需补齐Q-learning类SOTA对比和通信丢失的进一步理论证明。

---

## 1. 课题研究背景和目标

### 1.1 课题背景

这一部分建议放三层内容：

- 追逃博弈本身的重要性：
  - 多智能体追逃属于微分博弈、协同控制和强化学习交叉问题；
  - 在无人机协同拦截、机器人围捕、对抗规划等场景中有应用价值。
- 多对多场景的难点：
  - 非线性动力学；
  - 执行器饱和；
  - 多智能体目标分配与组内协调；
  - HJI方程高维、难解析。
- 你的问题意识：
  - 单纯的个体最优追踪并不自动等于组内安全协同；
  - 当多个追逐者被分配到同一逃避者时，可能出现轨迹接近、交叉甚至危险穿越；
  - 因此需要研究一种在保持主追踪性能的同时增强组内分离能力的方法。

### 1.2 课题目标

建议写成三个层次：

- 完成非线性多智能体追逃仿真与近似最优控制框架的实现；
- 在该框架上设计并验证带解析通信项的扩展控制方法；
- 通过标准场景和构造场景，评估其在追踪性能、组内最小间距、计算代价和通信鲁棒性方面的表现。

不要写成：

- “全面超越基线”
- “已经彻底解决碰撞问题”

这里的结论口径：

- 已经完成从训练、评估、统计到可视化的完整实验链路；
- 系统具备多场景复现实验能力。

### 2.2 解析通信项与平滑因子扩展

放这些内容：

- 同组追逐者间建立通信关系；
- 引入解析协调项，作用于相对速度和相对位置误差；
- 使用平滑pairwise放大因子，使近距离时协调作用增强；
- 说明该项的目标是“软分离/风险抑制”，不是硬约束安全控制。

这里的结论口径：

- 该扩展的设计目标是提高组内空间分离能力；
- 方法保持了原主控制结构的可解释性，没有引入额外大规模深网络；
- 当前更适合表述为“带平滑安全增益的解析协调机制”。

### 2.3 对比实验与鲁棒性评估

放这些内容：

- 标准规模场景：`3v1 / 3v3 / 5v3 / 6v3 / 8v4`
- 构造的多对多交叉应力场景：`6v3`
- 全通信与通信缺失场景；
- 与传统AC/Q-learning类结构的时间对比。

这里提前埋一个中期报告的伏笔：

- 标准场景更适合看“性能保持性”
- 构造场景更适合看“危险交叉抑制能力”

### 3.3 标准场景实验结果

这里不要强调“明显更好”，而要强调“基本没有破坏主性能”。

建议结论直接这样写：

- 在标准通用场景中，加入解析通信项后，捕获时间、均值跟踪误差和团队误差与无解析项情形总体接近；
- 说明该扩展不会显著破坏原有追逃主任务；
- 在若干场景中，最小组内间距有一定改善，但这种改善并非在所有规模下都呈现为显著、单调的优势；
- 因此，标准场景下更适合将该方法表述为“性能保持前提下的结构性扩展”，而不是“全面性能提升”。

可直接采用的稳妥表述：

- “通用场景下，扩展方法与基线方法在主要追踪指标上差异不大，说明所引入的解析协调机制没有明显破坏原有控制框架的有效性。”

### 3.4 构造场景与安全性展示

这一节才是你最该强调的地方。

建议放：

- `6v3` 多对多交叉应力场景；
- 说明构造方式：每个逃避者对应两名追逐者，两者初始位于彼此目标偏置的对侧，需要发生换道交叉；
- 给出核心结果：
  - 无解析项：`min d_min ≈ 0.995 m`，在 `d_safe = 50 m` 内停留 `1.5 s`
  - 有平滑解析项：`min d_min ≈ 83.723 m`，危险带停留时间 `0.0 s`

这一节的推荐结论：

- “在专门构造的多对多交叉场景中，解析通信项能显著抑制组内危险交叉。”
- “该结果说明该方法的主要价值不在于一般场景下全面改写追踪指标，而在于在存在潜在交叉风险时提供额外的空间分离能力。”
- “代价是收敛过程更保守，因此应将其理解为安全性与激进追踪之间的折中，而非无代价增益。”

这是最适合放动图和 `d_min` 曲线的一节。
