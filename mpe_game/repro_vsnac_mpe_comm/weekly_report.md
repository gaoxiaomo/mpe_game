# 组会汇报

## 本周工作进展

上周老师建议从计算性能方面入手，跟原文做对比分析。但实际推进中发现两个问题：一是原文代码没有公开，复现后的实现细节不完全一致；二是计算量的对比很难做到公平，因为我们的框架多了通信协调层，单纯比时间意义不大。

所以换了一个思路，重新审视了原文（Xu2024）的方法本身。发现一个比较明显的不足：原文的多追逐者系统中，每个追逐者独立求解自己的最优控制，只关注最终的追踪误差收敛（也就是编队偏移量r），**但完全没有考虑追逐过程中追逐者之间的距离**。当多个追逐者被分配到同一个逃逸者时，它们的最优轨迹可能非常接近甚至交叉，存在碰撞风险。

基于这个发现，我在原有V-SNAC框架上增加了一层**通信协调机制**作为创新点：

- 在同组追逐者之间建立通信图，引入一个速度-位置耦合的协调势函数
- 把这个协调势加到值函数上构成增广值函数，追逐者的控制从增广梯度在tanh饱和内推导
- 因为tanh本身有界，所以追踪和协调之间的控制力分配是自然的，不需要额外调参

目前仿真部分已经完成：

1. **受控交叉场景**：构造了两个追逐者路径必须交叉的情况，无协调时直接碰撞（d_min≈0），加入协调后间距保持在1km以上
2. **6追3场景**：在六自由度飞行器模型上验证了追踪收敛符合UUB稳定性，动态目标分配有效，通信丢包15%下仍然正常收敛
3. 论文初稿（中英文）已基本完成，6页IEEE格式
